标签与归档功能、界面分析



\## 一、标签功能说明



标签用于对文章进行更细粒度的主题归类。与电影分类不同，标签不局限于电影类型，可以表示地区、风格、情绪等维度，例如“欧美”“治愈”“经典”。用户可以在首页文章卡片或文章详情页看到文章所属标签，点击标签后进入标签结果页，该页面列出所有具有该标签的文章。用户可以继续点击文章进入文章详情页进行阅读。标签与文章是多对多关系，一篇文章可以有多个标签，一个标签下也可以有多篇文章。



!\[标签显示区域](images/tag-display.png)



图 1 首页文章卡片中的标签显示区域。用户点击标签后进入该标签的文章列表页。



!\[标签结果页](images/tag-result.png)



图 2 标签结果页。页面列出该标签下的所有文章，用户可继续点击进入文章详情页。



\## 二、归档功能说明



归档功能用于按时间组织文章，帮助用户查找历史影评。用户点击顶部导航栏的“归档”进入归档页，页面按年份或月份分组展示文章列表。用户可以从归档页点击文章进入文章详情页阅读。



!\[归档页](images/archive.png)



图 3 归档页。页面按时间分组展示文章，用户可点击文章进入详情页。



\## 三、界面元素说明



| 页面 | 元素 | 功能 |

|---|---|---|

| 标签显示区域 | 标签名称 | 标识文章主题，点击进入标签结果页 |

| 标签结果页 | 标签标题、文章列表、文章标题、摘要、发布时间、阅读量 | 展示该标签下所有文章，供用户继续点击阅读 |

| 归档页 | 年份/月份分组、文章标题、发布时间 | 按时间展示文章，方便查找历史文章 |



\## 四、页面流转说明



\- 首页 / 文章详情 → 点击标签 → 标签结果页 → 点击文章 → 文章详情页

\- 首页 → 点击“归档” → 归档页 → 点击文章 → 文章详情页
