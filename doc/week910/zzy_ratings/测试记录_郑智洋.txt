# ratings 功能测试记录（组员5：郑智洋）
环境：Windows 11 / Django 5.2.17 / MySQL 8.0.46 / Edge

01 未登录评分拦截
   步骤：未登录状态在文章页点击星星
   预期：提示先登录　实际：弹出"请先登录后再评分"　结论：通过（截图01）

02 首次评分
   步骤：zyy登录后点击第5颗星
   预期：显示5.0分(1人评分)我的5星　实际：一致　结论：通过（截图02）

03 修改评分
   步骤：同一篇文章改点第3颗星
   预期：3.0分(1人评分)，人数不变仅分数变　实际：一致　结论：通过（截图03）

04 非法分值拦截
   步骤：通过开发者工具fetch提交score=9
   预期：服务器返回400，数据不入库　实际：状态码400　结论：通过（截图04）

05 多用户评分汇总
   步骤：test账号对zyy评3分的文章评2星
   预期：平均分2.5分(2人评分)　实际：一致　结论：通过（截图05）

06 无评分文章展示
   步骤：打开无人评分文章
   预期：显示"暂无评分"无异常　实际：一致　结论：通过（截图06）

07 数据不重复核验
   步骤：Django shell查询全部评分记录
   预期：同一用户+同一文章组合无重复
   实际：共3条记录，用户+文章组合均唯一　结论：通过（截图07）

08 唯一约束核验
   步骤：SHOW CREATE TABLE ratings_rating
   预期：存在唯一索引　实际：UNIQUE KEY unique_user_article_rating(user_id,article_id)
   结论：通过（截图08）

调试记录：功能联调首次提交报403 Forbidden（CSRF校验失败），
经F12定位原因为页面未渲染csrf_token导致无csrftoken cookie，
修复方案为组件内嵌{% csrf_token %}并由JS读取隐藏域值，复测通过。
